# Thread notes

Each thread has a private Markdown notes pad at the bottom of the thread details card. Press
`mod+shift+u`, or run **Focus thread notes** from the command palette, to start typing in it; press
`mod+shift+u` again to return to the composer. Reaching the notes opens the thread details card if
it is closed.

Notes save automatically as you type and are stored on the environment that runs the thread, so
they survive restarts and appear on any web or desktop client connected to that environment. Agents
never see them.

While editing, `mod+l` toggles the checkbox on the current line, or on every selected line, and
turns a plain line or list item into a task. Click the rendered notes to edit them, and press `Esc`
to stop editing. Task list items (`- [ ] item`) can also be ticked without opening the editor.
Clearing the text removes the notes.

Notes are not available on mobile or for a draft thread that has not been sent yet.
