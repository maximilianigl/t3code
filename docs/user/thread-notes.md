# Thread notes

Each thread has a private Markdown notes pad in the thread details card. Press `mod+shift+u`, or
run **Toggle thread notes** from the command palette, to show or hide it. Showing notes opens the
thread details card if it is closed.

Notes save automatically as you type and are stored on the environment that runs the thread, so
they survive restarts and appear on any web or desktop client connected to that environment. Agents
never see them.

Click the rendered notes to edit them, and press `Esc` to stop editing. Task list items
(`- [ ] item`) can be ticked without opening the editor. Clearing the text removes the notes.

Whether notes are shown is remembered per client, for every thread. Notes are not available on
mobile or for a draft thread that has not been sent yet.
