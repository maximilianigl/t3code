# Desktop notifications

The T3 Code desktop app sends a system notification when an agent finishes, fails, needs approval,
or needs your input. It only sends notifications while T3 Code is in the background. Select a
notification to focus the app and open its thread, including threads from remote environments.

Desktop notifications are enabled by default. Turn them off under **Settings → General → Desktop
notifications**.

Your operating system can also block notifications for T3 Code. If notifications are enabled in the
app but do not appear, check the system notification settings for T3 Code.

Mobile push notifications use the separate **Publish agent activity** environment setting.
